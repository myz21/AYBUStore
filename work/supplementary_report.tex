\section*{How to Use This Template}
This document is the supplementary project description requested in the course brief. According to the uploaded project description, the report must be written in English and should support the official T\"UB\.{I}TAK 1001 application form.

\textbf{Important note on scores:} the course uses two rubrics at the same time: an adapted T\"UB\.{I}TAK panel rubric (60 pts) and a CENG306 software engineering rubric (40 pts). Because of that, one section may contribute to more than one grading criterion. The score labels below therefore show the \textbf{related grading criteria and their maximum rubric weights}, not a strict one-to-one section total.
